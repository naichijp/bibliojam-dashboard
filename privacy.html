プライバシーポリシー

BIBLIO JAM レポート（番組運営のための分析ツール）　制定日：2026年10月14日

このページは、ポッドキャスト番組「BIBLIO JAM」の運営者が、番組の分析のために使う次の2つの道具（以下「本ツール」）での情報の扱いを定めるものです。

  • 番組メンバーだけがログインして見る分析ダッシュボード（このサイト）
  • 番組の運営者が、自分の YouTube チャンネルの分析データを読み取るための道具（YouTube API Services を使います）

本ツールは一般の方に向けたサービスではありません。

取得する情報

  • ダッシュボードに Google アカウントでログインしたときの、メールアドレスと表示名。番組メンバーかどうかを照合するために使います。
  • YouTube API Services を通じて取得する、運営者自身の YouTube チャンネルの統計情報（動画ごとの視聴回数、総再生時間、平均視聴時間、インプレッション、クリック率、チャンネル登録者の増減、流入経路など）。

視聴者個人を特定できる情報は取得しません。

利用目的

番組の内容と制作を改善するための分析と、その結果を番組メンバーに表示することだけに使います。広告や販売には使いません。

保存と共有

  • 取得した情報は、運営者が管理するデータベース（Supabase）に保存します。
  • 見られるのは、運営者が登録した番組メンバーだけです。第三者には提供しません。

YouTube API Services について

  • 本ツールは YouTube API Services を使っています。利用にあたっては YouTube 利用規約 が適用されます。
  • Google による情報の扱いは Google プライバシーポリシー をご覧ください。
  • 本ツールへのアクセスの許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消した場合、YouTube API Services で取得した情報は、YouTube API Services の規約で定める期間内に削除するか、更新を止めます。

お問い合わせと改定

本ポリシーについてのお問い合わせは、番組の運営者までご連絡ください。内容を改定するときは、このページを更新し、制定日・改定日を記載します。
